## 1. 不可偏离的设计基线

### 1.1 风格原则

- 苹果负责清晰层级、克制材质、连续圆角、自然转场与弹簧物理感。
- 小米负责高信息密度、胶囊控件、快捷操作、即时按压和触感反馈。
- 视觉层级仅三级：页面背景、实底卡片、玻璃浮层。卡片不使用毛玻璃；玻璃只用于抽屉、导航栏、悬浮工具栏等浮层。
- 列表紧凑、详情舒展；不得用大片无意义留白，也不得堆叠描边和阴影。
- 统一 24 栅格线性图标，不混用 emoji；品牌图标必须置于统一尺寸容器内。
- 维持开发者控制的卡片尺寸，不提供用户拖拽/缩放卡片的功能。
- 不造假数据、假评分、模拟账单或无动作占位按钮。

### 1.2 设计令牌（来自设计说明书 v1.1）

| 类别 | 规范 |
|---|---|
| 品牌色 | 浅色 #0D8279；深色 #2BA79C |
| 页面底色 | 浅色 #F8F8FA；深色 #121214 |
| 分组底色 | 浅色 #F2F2F7；深色 #1C1C1E |
| 卡片 | 实底 + 1px 低对比描边，不加卡片投影 |
| 玻璃浮层 | 浅色白 72% / 深色 68%，blur 20，仅浮层使用 |
| 字阶 | 34 / 28 / 22 / 20 / 17 / 15 / 14 / 13 / 12 / 11sp |
| 间距 | 仅 4、8、12、16、20、24、32dp |
| 圆角 | 28 / 20 / 12 / full |
| 页面左右边距 | 16dp |
| 卡片内边距/间距 | 16dp / 12dp |
| 列表行高 | 单行 56dp，双行 64dp |
| 图标 | 24 栅格、约 1.7dp 描边、圆润端点；常用 18/20/24dp |

### 1.3 动效与触感

- 按压反馈必须在 150ms 内可感知；按钮缩放目标约 0.94，卡片约 0.96，并配合透明度/颜色变化。
- 快速反馈约 150ms；内容替换/展开约 250ms；页面推送约 320ms；抽屉约 380ms 弹簧；弹窗约 240ms。
- 列表按 40ms/项错峰进入；同一时刻最多两处元素运动。
- 动效必须解释状态变化，可中断；禁止无意义呼吸、循环发光、连续抖动。
- 触感分级：普通轻触 light；复制/长按等重要操作 medium；危险操作 warning/heavy（设备不支持时优雅降级）。
- 所有异步动作需有加载、禁用、成功/失败反馈；不可只换文案却没有真实动作。
- 提供无障碍语义、可读状态和至少 44dp 触控热区；减少动态效果需尊重系统动画设置。

### 1.4 重构边界

- 只改 UI 表现与交互反馈，不改业务逻辑、数据结构和接口语义。
- 不改 WalletConnect SDK 内部页面；只改自有外层容器、进入/退出转场和遮罩。
- 不改 WebView 内网页内容；只改浏览器容器、加载态、安全提示、主机条和底部工具栏。
- 不新增设计说明书之外的业务功能。
- 不放宽 TLS、DApp origin、WalletConnect 或其他安全约束来换视觉效果。

## 4. 本轮执行顺序

1. **P0 设计系统审计**：逐个核对令牌、基础组件、按压反馈、触感分级、主题适配；修正基础组件后再批量应用。
2. **P0 浏览器容器**：处理用户当前无法打开网页的问题与容器视觉；保留 TLS/DApp 安全边界。
3. **P0 钱包与记账**：钱包管理、钱包详情、记账中心、真实记账流程；禁止模拟账单。
4. **P1 首页/搜索/空投**：首页、导航抽屉、全局搜索、空投库/公告。
5. **P1 项目/社区/个人中心**：按页面密度和详情层级统一。
6. **P2 全局回归**：浅深色、屏幕尺寸、状态覆盖、触感、无障碍、转场性能。
7. 全部完成后再统一运行 Gradle、Android tests、backend tests、CI 和 APK 构建；中途不宣称构建通过。

## 5. 防止重复修改的强制更新流程

每次实施一个页面/组件时，必须按以下顺序执行：

1. **先读本台账**，确认该页面当前状态、已完成事项和明确未完成项。
2. **检查代码现状**，不要因为台账写着“进行中”就重复添加已存在的组件或逻辑。
3. **先更新本台账中的计划/目标**（如发现需要调整范围，先记录原因）。
4. 修改代码并进行针对性静态检查。
5. **同一提交更新本台账**，记录：
   - 日期；
   - 修改页面/文件；
   - 实际完成内容（具体到组件/状态）；
   - 未完成项与原因；
   - 自动化测试/编译/设备验收状态；
   - 对应 commit SHA。
6. 下一轮从本文件未完成事项继续，不重做已完成工作。
7. 只有编译、自动化测试和必要真机验收均通过后，才把状态从“代码已落地待验收”升级为“已验收”。
